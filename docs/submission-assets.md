These stills are generated by the Playwright submission-asset mode against the production UI, registry, and tool executors. The browser test supplies a test-only `document.modelContext` harness; real supported-browser WebMCP evidence is recorded separately in [judging-evidence.md](judging-evidence.md), including deployed-origin Gate 8 evidence.

Regenerate from a clean checkout:

```bash
CAPTURE_SUBMISSION_ASSETS=1 npm run test:e2e
CAPTURE_PRODUCT_ASSETS=1 npx playwright test tests/browser/live-site.e2e.ts
```

PowerShell:

```powershell
$env:CAPTURE_SUBMISSION_ASSETS = "1"
npm run test:e2e
Remove-Item Env:CAPTURE_SUBMISSION_ASSETS
$env:CAPTURE_PRODUCT_ASSETS = "1"
npx playwright test tests/browser/live-site.e2e.ts
Remove-Item Env:CAPTURE_PRODUCT_ASSETS
```

Do not substitute these stills for the required under-three-minute live WebMCP demo video.
